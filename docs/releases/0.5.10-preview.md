- **Signed updates:** the updater reads the public releases anonymously over HTTPS, without the GitHub CLI, and installs a release only when its checksum file carries a signature from a pinned release key. The signed line names the file and its version, so an old setup cannot be republished under a newer tag.
- Each release is built and attested by CI from this repository.
- **Diagnostic report** in Status & help, for bug reports: versions, displays, scaling, graphics adapters and drivers, layout and app status, without window titles, paths, user or computer names.
- Issue templates and a security policy.
