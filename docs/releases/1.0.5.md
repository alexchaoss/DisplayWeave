Changes after several antivirus engines flagged earlier setups, and a report about fullscreen video in a browser.

- **New setup** built with Inno Setup, replacing the custom setup and its PowerShell installer. Its uninstaller is code-signed too. The portable ZIP is compressed again.
- **A signed native launcher** replaces the PowerShell launcher, so no PowerShell runs at install or sign-in.
- The native helpers are windowed programs with version information.
- **A fullscreen browser window** is fitted again as soon as it spreads over the whole display, with no retry delay.
