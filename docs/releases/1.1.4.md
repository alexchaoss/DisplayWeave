- **A layout keeps its display when that display is off at start.** If your monitor was asleep, off or switched away when DisplayWeave started, the layout used to move to another display, and exiting saved that. Now the layout's display is listed as "not connected", nothing is handled until it is back, and handling resumes by itself when it is.
- **A failed profile switch no longer stops handling.** If the new profile cannot be saved, the current profile stays in use and handling goes on as before.
- **Change the rule of an app that is not running.** On App rules, choose another option or region for a saved app and Save; the rule applies the next time the app starts.
- **Splitting or merging regions no longer leaves rules broken.** When you save the layout, Force fullscreen and Maximize in region rules pinned to a region that was split or merged use the region the app is in, and the message says how many changed. Borderless in region and Centered fullscreen rules need a region, so choose a new one for them on App rules.

**Known issues**

- An app that maximizes itself while a Force fullscreen rule confines it is left un-maximized at its region's size when handling pauses. Maximize it again.
- Restart as administrator still starts the app from your user-writable install folder; see SECURITY.md, "Known limits".
