- **Your own keyboard shortcuts:** a Shortcuts tab records keys and what they do for the app in front (fit, borderless or force it into a region, release it, pause or resume handling, switch profile). The built-in Ctrl+Alt+Shift shortcuts are gone.
- **Layout profiles** keep whole layouts with their own app rules; switch from the Layout tab or the tray.
- **Remembered regions:** an app that starts maximized or fullscreen goes back to the region it was last fitted into. Hold Shift while maximizing to skip the fit once.
- A borderless game that resizes itself back gets a notification that saves a Borderless in region rule for it when clicked.
- Rules ignore the part of a window class that changes on every run, tell Store apps apart, and show when they last applied. The layout and its rules follow their monitor when Windows renames the display.
- **Crash recovery:** windows shown without their title bar are recorded, so a crash or the next start gives them back.
- A display change waits for the display to come back only while a fullscreen game is in front. Handling slows to once a second when nothing moves.
- **Activity log**, also included (scrubbed) in the Diagnostic report.
- **Safer updates:** the setup is checked again right before it runs; the launcher goes back to the previous version after two failed starts, the tray can go back by hand, and a version you gave up on is skipped.
- Administrator mode copies only the native helpers this build lists and checks each copy against its build hash.
