- **Updates no longer make you reopen a browser that has a Force fullscreen rule.** A new version, or a restart of DisplayWeave, now takes over the component already loaded in the browser. Before, reconnecting to a browser window always failed ("The existing DisplayWeave worker did not acknowledge reconnection", Windows error 1400), so the rule stopped applying until the browser was reopened. Other apps were already taken over.
- The fix is in the new version's helper, so it should also take over a browser that got the component from an earlier version, without reopening it for this update.

**Known issues**

- An app that maximizes itself while a Force fullscreen rule confines it is left un-maximized at its region's size when handling pauses. Maximize it again.
- Restart as administrator still starts the app from your user-writable install folder; see SECURITY.md, "Known limits".
