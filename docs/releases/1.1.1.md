App rules is now a list beside a detail view instead of one long page.

- The list groups apps as **Saved** (rules of the active profile, grayed when the app is not running) and **Not saved** (running apps without a rule). The right side shows the selected app's option, region and Save.
- **Automatic (no rule)** is the first option; saving it removes the rule. It replaces Remove rule and the separate saved-rules table.
- Save is enabled only when something changed. A rule of an app that is not running can only be removed.
- Apply saved rules moved to the automatic handling banner. A rule without a pinned region no longer shows its region as missing.

Region handling is unchanged from 1.1.0.
