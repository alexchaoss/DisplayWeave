Several antivirus engines flagged the 1.0.2 setup. This version removes the installer patterns that look like a dropper, without hiding anything:

- PowerShell runs with the RemoteSigned execution policy instead of Bypass in the setup, the Start menu shortcut, the startup entry and the app's startup setting.
- The installer script and the launcher are code-signed; the launcher is a packaged file instead of text inside the installer.
- The uninstaller is removed after it exits by a copy of itself in %TEMP%, instead of a command-prompt delete command.
