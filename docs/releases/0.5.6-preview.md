The first public release of DisplayWeave: it confines fullscreen and maximized apps to customizable, non-overlapping regions of an ultrawide monitor while the desktop and taskbar keep their normal size.

- Region editor with movable ruler pins and pixel spacing, automatic region handling, per-app rules (Force fullscreen, Ignore, Maximize in region), a tray app, a per-user setup with uninstall, and automatic updates.
- Apps no longer need a restart because of a component left by an earlier build.
- Presets follow the display's size, aspect ratio and Windows scaling.
- An error while handling one app leaves only that app alone. Status & help lists the handled apps with their display, region and status.

**Known issue:** automatic handling can load the component into browser windows, which can make them crash. Fixed in 0.5.9-preview.
