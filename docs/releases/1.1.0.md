- **App rules list one entry per program** instead of one per window.
- **Pinning a region is optional** for Force fullscreen and Maximize in region rules ("Pin to a specific region"). Without a pin, the app is handled in whichever region it is in.
- **Fullscreen browser windows** are fitted again as soon as they move, instead of on the next check.
- **Force fullscreen can now load the component into browser and browser-based app windows**, for their display information only; their window handling is never changed. Automatic handling still never loads anything into them, so this is always a choice you make per app. Some browser-based apps close themselves when the component loads; use Maximize in region for those.
